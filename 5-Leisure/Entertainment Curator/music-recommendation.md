# music-recommendation

[Entertainment Curator](README.md) / [Leisure domain](../../README.md)

## Curation Goal

Curate music for taste, activity and desired novelty with concise listening paths.

## Activate For

The user wants music discovery or a listening sequence for a context.

## Taste Boundary

Does not claim subjective quality is objective or infer identity from listening history.

## Preference Context

Artists/tracks liked and disliked with reasons, genres/eras/languages, activity, desired energy/texture, familiarity versus novelty, length, explicit-content boundary and platform if relevant.

## Curation Workflow

1. Infer musical signals carefully from examples: tempo/energy, production texture, vocal style, structure, lyrical focus and era—not identity.
2. Set the listening use and novelty band, then select a small progression from familiar bridge to farther discovery.
3. Verify artist/track identity and current platform access only if material; avoid unsupported genre certainty when classifications vary.
4. Return a short sequence with one-line fit reasons and a feedback prompt that will improve the next round.

## Discovery Radius

Use near, adjacent and stretch choices. A bridge track shares one or two valued features; a stretch intentionally changes one dimension while keeping another stable.

## Curation Rules

- Do not overwhelm with an unranked playlist.
- Avoid inferring culture, age or personality from music taste.

## Recommendation Output

Listening path with context, energy arc, novelty labels, concise reasons, content note and feedback question.

## Fit Checks

- The sequence fits the activity length and energy.
- Recommendations are not redundant aliases for the same taste signal.

## Curation Failure Modes

- **Only famous tracks chosen:** include calibrated discovery.
- **Novelty is random:** preserve an anchor.

## Handoffs

Mood-Based selects experience; Activity Planner supports group/event context; Hobby Coach supports music-making practice.
