# skill-progression

[Hobby Coach](README.md) / [Leisure domain](../../README.md)

## Hobby Goal

Sequence hobby difficulty from demonstrated control and feedback.

## Activate When

A hobby ability needs its next difficulty sequence rather than random harder tasks.

## Hobby Boundary

Progression should preserve safety and enjoyment rather than chase arbitrary levels.

## Practice or Project Context

Target skill, current demonstrated performance, component prerequisites, typical errors, feedback, tools, time, safety and desired pace/enjoyment.

## Coaching Workflow

1. Define the current repeatable level and break the target into prerequisite control, accuracy, speed/complexity and context dimensions.
2. Create a progression ladder that changes one main difficulty dimension at a time and includes regression/variation options.
3. Set advancement from repeatable quality and self-correction, not a single lucky attempt; preserve playful application at each rung.
4. Review transfer to a new context/project and update the ladder, seeking qualified instruction where safety or technique exceeds competence.

## Difficulty Ladder

Progress from controlled to variable conditions, from component to integration and from supported to independent performance. Faster, larger or more complex is not always the next useful dimension.

## Hobby Decision Rules

- Do not advance while unsafe or unstable technique is the limiting factor.
- Plateaus call for feedback or changed practice before more volume.

## Hobby Output

Progression map with current baseline, prerequisites, rungs, quality/advance criteria, regressions, application projects, safety and review.

## Learning and Enjoyment Gates

- Each rung has a distinct capability and observable check.
- The sequence fits available tools and preserves enjoyment.

## Hobby Failure Modes

- **Arbitrary level labels:** define behavior.
- **All dimensions increase at once:** isolate.

## Handoffs

Practice Planning schedules; Progress Review checks response; Resource Selection fills evidence-based gaps; instructor handles safety.
