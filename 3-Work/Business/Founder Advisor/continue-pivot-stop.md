# Continue Pivot Stop

Context: [Founder Advisor](README.md).

## Purpose

Choose whether to continue, change the thesis, pause, or exit an initiative after new evidence.

## Activate When

A bet misses gates, its premise weakens, or continued spending needs renewed justification.

## Do Not Use When

Ordinary delivery variance belongs with Project Manager; a pivot changes the strategic hypothesis, not merely the deadline.

## Required Context

**Needed:** Original thesis and gates, new evidence, remaining runway, exit obligations, and credible alternatives.

**Can be deferred or bounded:** Absent original gates require reconstructing the decision rationale from contemporaneous records, not inventing a favorable threshold after results.

## Workflow

1. Compare evidence with the original thesis. Separate weak demand, execution failure, measurement failure, and an external change; each calls for a different response.
2. Estimate forward-only value and cash exposure of continue, repair, narrow, pivot, pause, and stop. Include customer, employee, contract, data, and reputation consequences of exit.
3. For a pivot, state which hypothesis changes, which evidence supports the new path, and which assets are genuinely reusable. Do not call another untested idea a validated pivot.
4. Set a bounded final test only if it can resolve the decision before resources become inadequate. Identify the cost of another review cycle.
5. Recommend an action and an orderly transition: owner, obligations, communication approval, resource release, and conditions for re-entry.

## Decision Rules

- If the next evidence arrives after the downside becomes unaffordable, reduce or stop exposure now.
- If measurement is broken, repair it only within a bounded cost; uncertainty is not unlimited permission to continue.
- If stopping has obligations, fund a responsible wind-down rather than treating stop as zero cost.

## Output Contract

Decision with thesis status, option comparison, incremental exposure, selected path, exit/transition plan, and executive approval needs.

## Quality Gates

- The recommendation survives excluding sunk costs and founder attachment.
- Continuation has a falsifiable gate; exit has an obligation owner and cash provision.

## Failure Modes

- Moving goalposts after every miss: preserve original and revised gates separately.
- Pivot disguises avoidance of failure: name the changed premise.

## Handoffs

Business/Product Strategists diagnose thesis; Financial Analyst tests survivability; Project/Operations Managers plan transition; legal/HR handle obligations; founder decides.
