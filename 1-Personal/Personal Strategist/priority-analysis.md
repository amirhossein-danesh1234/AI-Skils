# priority-analysis

[Personal Strategist](README.md) / [Personal domain](../../README.md)

## Purpose

Resolve what deserves attention now and what will deliberately receive less.

## Activate When

Competing personal commitments cannot all receive meaningful attention in the current season.

## Do Not Use When

Planner schedules accepted priorities; this skill may recommend doing less.

## Required Context

**Needed**

User values, mandatory obligations, active commitments, real constraints, deadlines and consequence of delay.

**Can be deferred or bounded**

Exact calendar placement belongs to Personal Planner after priority choices.

## Workflow

1. Separate essential obligations, chosen maintenance, active bets and optional requests. Identify the binding resource rather than ranking abstract importance alone.
2. Compare contribution to current values, urgency mechanism, cost of delay, reversibility and opportunity displaced. Challenge inherited commitments whose rationale expired.
3. Select a feasible focus set plus maintain, defer, delegate, decline and stop choices. Protect recovery and relationships the user explicitly values.
4. Set review triggers for changed evidence, deadline or season; do not reopen priorities at every new request.

## Priority Means Less Elsewhere

A priority that changes no allocation is only a label. Name the commitment receiving less, later or no attention. Urgency requires a consequence and deadline, not another person’s intensity. Doing less is valid when the portfolio exceeds capacity or maintenance burden.

## Decision Rules

- Mandatory does not mean infinite effort; choose a sufficient level where possible.
- If conflict is actually between life values, return it to explicit user choice instead of scheduling both.

## Output Contract

Focus portfolio with now/maintain/defer/stop, displacement, minimum sufficient levels and review trigger.

## Quality Gates

- The focus set fits the scarce resource when Planner later schedules it.
- Every defer/decline has a truthful consequence, not motivational punishment.

## Failure Modes

- **Everything important treated as top priority:** distinguish maintenance from active focus.
- **Recovery is the first silent cut:** include it as a real constraint/value.

## Handoffs

Planner turns accepted priorities into a week; Communication helps decline or renegotiate commitments respectfully.
