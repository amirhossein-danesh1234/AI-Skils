# financial-scenario-analysis

[Personal Finance Advisor](README.md) / [Personal domain](../../README.md)

## Purpose

Test affordability across coherent changes in income, costs and timing.

## Activate When

Affordability depends on uncertain income, costs, timing or external conditions.

## Do Not Use When

Scenarios are not forecasts and changing external facts require current verification.

## Required Context

**Needed**

Base financial model, decision horizon, sensitive variables, obligations, current source dates and owner downside limits.

**Can be deferred or bounded**

Probabilities may be omitted; estimates and scenario inputs stay labeled and independently changeable.

## Workflow

1. Reconcile a current base case from known amounts, separating estimates/forecasts/assumptions. Identify variables that can change the decision.
2. Build a few coherent scenarios, including delayed income and correlated cost pressure where plausible. Do not combine impossible extremes.
3. Calculate liquidity low points, savings progress and obligations under each scenario using the same definitions/horizon.
4. Compare staged, reduced, delayed or no-action choices; add signposts and latest-useful decision dates.

## Scenario Labels

A scenario is conditional arithmetic, not a forecast. Current price, rate, tax, benefit and law inputs need dated authoritative verification at use time. Do not assign convenient probabilities or average scenarios into an expected future unless a defensible basis exists.

## Decision Rules

- If the decision is safe only in an optimistic case, state that dependence.
- If an external fact can change the outcome cheaply to verify, verify before the consequential commitment.

## Output Contract

Base model, scenario assumptions, results/shortfalls, robust or contingent option and revisit signposts.

## Quality Gates

- Known, estimate, forecast, assumption and scenario are visibly distinct.
- Each scenario is internally coherent and reconciles cash rather than only income/expense totals.

## Failure Modes

- **Stress test becomes catastrophizing:** use plausible decision-sensitive variables.
- **Base case treated as most likely without evidence:** call it reference only.

## Handoffs

Cash Flow supplies dated model; Strategist addresses broader choice; qualified advisers validate tax/legal/investment issues.
