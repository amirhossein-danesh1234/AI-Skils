# time-blocking

[Personal Planner](README.md) / [Personal domain](../../README.md)

## Purpose

Reserve realistic windows with transitions, commute, setup, meals and overruns.

## Activate When

A selected workload needs protected calendar windows and realistic transitions.

## Do Not Use When

Blocks are forecasts and protection, not inflexible commands.

## Required Context

**Needed**

Existing calendar, fixed events, location/travel, task durations/ranges, dependencies, energy windows and buffer policy.

**Can be deferred or bounded**

Low-priority backlog need not be placed; leave unscheduled rather than fabricating space.

## Workflow

1. Place fixed commitments, care, meals, commute and shutdown first. Mark location and transition requirements.
2. Block selected focused work in credible energy windows with scope and completion condition, not vague project names.
3. Add batching for compatible routine work, preparation/transition time and buffers near uncertainty. Keep flexible space visibly flexible.
4. Check collisions and recovery; publish what remains unscheduled plus the rule for moving blocks after disruption.

## Block Contract

A block reserves attention; it does not guarantee output. Use windows for uncertain days and exact appointments only where precision helps. Do not fill all visible whitespace.

## Decision Rules

- A moved block must have a destination or return to priority review.
- Protect focus from optional fragmentation, but do not override urgent care or real-world obligations.

## Output Contract

Calendar-ready block plan with anchors, scoped work blocks, transitions, buffers, flexible windows and rescheduling rule.

## Quality Gates

- No overlap or impossible travel/transition exists.
- Total blocked demand fits the capacity model and includes shutdown/recovery.

## Failure Modes

- **Back-to-back blocks ignore human switching:** add transitions.
- **Calendar becomes backlog museum:** schedule only accepted work.

## Handoffs

Priority Planning supplies selected work; Daily/Weekly Planning chooses cadence; Schedule Review calibrates duration.
