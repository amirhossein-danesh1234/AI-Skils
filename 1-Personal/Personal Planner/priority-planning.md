# priority-planning

[Personal Planner](README.md) / [Personal domain](../../README.md)

## Purpose

Translate accepted priorities into scheduled attention and explicit deferrals.

## Activate When

Accepted goals and obligations compete for limited planning capacity in a defined period.

## Do Not Use When

Strategist resolves value conflicts; this skill works within them.

## Required Context

**Needed**

Candidate commitments, due dates/consequences, value, effort/energy demand, dependencies and capacity.

**Can be deferred or bounded**

Fine scheduling waits until the survivable set is chosen.

## Workflow

1. Separate true obligations, time-sensitive opportunities, maintenance and optional aspirations. Verify claimed deadlines and consequences.
2. Apply Personal Strategist priorities to the planning horizon, then compare each item with matching capacity and dependency windows.
3. Choose the survivable set and explicitly defer, reduce, delegate or decline the rest. State what each new item displaces.
4. Set an interruption policy and a trigger for reopening priorities when facts—not anxiety—change.

## Capacity-Constrained Queue

A priority without reserved capacity is a preference, not a plan. Urgency does not automatically override importance, and importance does not create time. The output must contain a not-now set.

## Decision Rules

- Protect due obligations and essential maintenance before optional optimization.
- When two commitments cannot coexist, expose owner-level trade-offs rather than double-booking.

## Output Contract

Ranked planning queue with reasons, capacity cost, accepted set, not-now set, displacement and reprioritization triggers.

## Quality Gates

- Accepted work fits credible capacity.
- Each exclusion has a disposition rather than disappearing.

## Failure Modes

- **Everything labeled high priority:** force sequence and exclusion.
- **Ranking ignores energy type/dependencies:** test executable order.

## Handoffs

Strategist owns value-level priority; Capacity Planning tests load; Weekly Planning turns the selected set into a schedule.
