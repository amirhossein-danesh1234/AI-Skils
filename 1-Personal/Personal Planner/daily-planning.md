# daily-planning

[Personal Planner](README.md) / [Personal domain](../../README.md)

## Purpose

Choose a resilient set of outcomes and maintenance for one actual day.

## Activate When

The user needs a realistic plan for one day or must recover after the day changes.

## Do Not Use When

Not a comprehensive life priority review or an attempt to fill every gap.

## Required Context

**Needed**

Fixed events, sleep/wake window, travel/transitions, essential care/meals, task priorities, effort ranges, energy and current state.

**Can be deferred or bounded**

Optional tasks and precise start times may be deferred; use windows when the day is volatile.

## Workflow

1. Anchor immovable events and basic needs, including realistic preparation and travel. Check the day’s starting energy and any carryover.
2. Select one primary outcome and a very small supporting set within dependable focus and low-energy capacity. Split large work into finishable next actions.
3. Place demanding work in plausible energy windows and routine work elsewhere. Add transitions, buffer and a shutdown boundary.
4. Define a disruption rule: preserve essentials and the primary outcome if feasible, then remove optional work before consuming recovery. End with a brief reset.

## Minimum Viable Day

A day plan is a commitment filter, not a place to display the whole backlog. Use a minimum version for constrained days. Completion is not improved by silently borrowing from sleep, meals or required care.

## Decision Rules

- If the first half of the day slips materially, replan from now rather than compressing the original plan.
- If no focused window remains, choose maintenance or recovery honestly instead of relabeling routine time.

## Output Contract

Day plan with anchors, primary outcome, bounded supporting actions, energy placement, buffer, minimum version and disruption rule.

## Quality Gates

- The plan fits the available day including transitions.
- Every scheduled item has an actionable scope and optional work is visibly optional.

## Failure Modes

- **Minute-level plan creates churn:** use blocks/windows appropriate to uncertainty.
- **Carryover repeatedly dominates:** return excess commitments to weekly review.

## Handoffs

Weekly Planning supplies the commitment set; Time Blocking places work; Schedule Review diagnoses recurring drift.
