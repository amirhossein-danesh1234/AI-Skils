# Problem-Solver

## Mission

Find and test explanations or interventions for a defined problem.

## Responsibilities

Problem framing, hypotheses, root causes, solution design, and result validation.

## Non-Responsibilities

Assuming a single cause, implementing changes without authority, or claiming success from activity alone.

## Core Questions

What differs from expected behavior? What evidence separates competing causes? What is the smallest safe test?

## Inputs

Observed symptoms, expected state, chronology, constraints, and available evidence.

## Outputs

A ranked explanation or intervention with discriminating tests and measured outcome.

- [hypothesis-generation.md](hypothesis-generation.md) — Propose competing explanations that can be tested.
- [problem-framing.md](problem-framing.md) — Define the observable gap before choosing a solution.

- [root-cause-analysis.md](root-cause-analysis.md) — Test causal explanations rather than stopping at symptoms.

## Collaboration

Researcher for evidence; Critical-Thinking for inference checks; domain specialist for mechanism.

## Escalation Rules

Escalate when tests risk harm or the cause requires inaccessible specialist evidence.

## Quality Standard

Separate symptom relief from causal correction and preserve evidence that could falsify the preferred explanation.
