# Prioritization

Context: [Planner](README.md).

## Purpose

Order ready work against accepted priorities and scarce capacity.

## When to Use

Ready work competes for limited capacity inside already accepted goals.

## Boundary

Changing strategic goals requires Decision-Analyst and the owner.

## Inputs

Accepted priorities, mandatory obligations, candidate outcomes, dependencies, effort ranges and bottleneck resources.

## Method

1. Separate mandatory/time-critical obligations from discretionary candidates and identify which work is actually ready. A blocked high-value task may require a prerequisite rather than idle waiting.
2. Compare incremental outcome value, cost of delay, dependency unlocks, reversibility and burden on the scarce resource. Preserve a no-new-work or defer option.
3. Select a feasible sequence and work-in-progress limit appropriate to actual capacity. Avoid starting many attractive tasks that all wait on the same specialist or approval.
4. Test whether plausible effort/value changes reverse the order. Use a small information task when it can resolve a sensitive ranking cheaply.
5. Publish do-now, next, defer and stop choices with the reason, displaced work and review trigger.

## Priority Is a Capacity Choice

A score alone is not a schedule. Two high-scoring tasks may be mutually infeasible; a low-scoring prerequisite may unlock the highest-value outcome. Do not divide guessed value by guessed effort to create false precision. If the disagreement concerns which goal matters, return it to the owner instead of hiding a strategic decision in task ordering.

## Output

A capacity-feasible priority order, explicit not-now list, prerequisite actions and reorder triggers.

## Quality Checks

- Each started item has a path to completion rather than only available start capacity.
- Cost of delay and displaced obligations are represented without automatically treating every urgent request as mandatory.

## Handoffs

[Decision-Analyst](../Decision-Analyst/README.md) structures competing objectives; [resource-planning](resource-planning.md) confirms feasibility.
