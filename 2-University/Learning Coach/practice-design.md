# practice-design

[Learning Coach](README.md) / [University domain](../../README.md)

## Learning Aim

Design exercises that target a specific ability and produce diagnostic feedback.

## Activate When

A specific academic ability needs exercises that teach and diagnose it.

## Coaching Boundary

More questions are not automatically better; difficulty and feedback must match the objective.

## Learner Evidence

Target capability, learner level, prerequisite evidence, representative task demands, common errors, available time/tools and feedback method.

## Coaching Loop

1. Define the observable operation to practice and the failure the exercise should reveal.
2. Create a progression from isolated component to integrated and varied cases, controlling difficulty one dimension at a time.
3. Require prediction or reasoning before solution exposure. Provide feedback keyed to error type and hints that preserve productive work.
4. Include a transfer item with changed surface features and set advancement, repeat or remediation criteria from performance.

## Desirable Difficulty

Difficulty is useful only when the learner can engage the target and receive corrective feedback. Random complexity, excessive load or trick wording does not create durable learning.

## Durable Learning Rules

- Mix practice after the component is understood enough to discriminate methods.
- Worked examples should fade support rather than remain permanent templates.

## Learning Plan Output

Practice set with target map, ordered tasks, hint ladder, solutions/checks, error codes, transfer item and mastery rule.

## Mastery Checks

- Each item has a reason to exist and tests the intended capability.
- Solutions expose reasoning and verification, not only final answers.

## Coaching Failure Modes

- **Many near-identical questions create fluency illusion:** vary representation and context.
- **Difficulty rises before feedback works:** repair the prerequisite first.

## Handoffs

Active Recall handles compact retrieval; tutors validate solutions; Knowledge Gap Analysis interprets recurring errors.
