# learning-plan

[Learning Coach](README.md) / [University domain](../../README.md)

## Learning Aim

Sequence prerequisites, explanations, practice and feedback toward demonstrable mastery.

## Activate When

A subject or capability needs a sequenced route from current knowledge to demonstrable outcomes.

## Coaching Boundary

Plan learning outcomes, not study-hour theater or an impossible syllabus.

## Learner Evidence

Target outcomes, deadline/horizon, prerequisite assessment, learner attempts, available capacity, resources, assessment context and feedback access.

## Coaching Loop

1. Express outcomes as observable explanations, derivations, problem types or creations; assess prerequisite evidence before sequencing.
2. Build dependency-ordered units that alternate concise instruction, guided example, unaided practice, feedback and transfer.
3. Fit the plan to real capacity with spacing and buffer. Select a small source set and define when tutor/research help is needed.
4. Set mastery gates and periodic replanning from performance data; reduce scope or extend horizon when the path is infeasible.

## Mastery Path

Time spent is not a completion criterion. Each unit exits when the learner can retrieve and apply the target under a stated condition, including a delayed or novel check where appropriate.

## Durable Learning Rules

- Teach prerequisites just in time unless a missing foundation blocks multiple outcomes.
- Plan only the detail needed until the next evidence checkpoint.

## Learning Plan Output

Learning roadmap with outcome/dependency map, study cycle, capacity schedule, resources, mastery checks, buffer and revision triggers.

## Mastery Checks

- Every activity produces evidence about a target ability.
- The sequence respects prerequisites and is feasible within the horizon or states the shortfall.

## Coaching Failure Modes

- **Syllabus copied into a calendar:** add learning and feedback loops.
- **Overplanning replaces first practice:** start with a diagnostic task.

## Handoffs

Academic Planner owns formal deadlines; subject tutors own correctness; Revision Planning manages later reviews.
