# citation-management

[Academic Writer](README.md) / [University domain](../../README.md)

## Communication Aim

Maintain verifiable source records and consistent claim-to-citation links.

## Activate For

A draft or research project needs accurate references and claim-level attribution.

## Writing Boundary

Never fabricate, guess or silently repair bibliographic details.

## Source Materials

Draft/claims, source library or identifiers/full texts, required citation style/version, reference manager format and authorship/attribution rules.

## Writing Workflow

1. Inventory citation-bearing claims and match each to a source actually checked at the supporting location.
2. Verify metadata against DOI/publisher/database records, preserving version, correction/retraction status and access dates where style requires.
3. Deduplicate records, maintain stable keys and apply style consistently to in-text citations, bibliography, figures/data/software and secondary citations.
4. Run bidirectional audit: every citation has a reference, every reference is cited, and high-stakes claims use appropriate primary/current sources.

## No-Fabrication Gate

If a reference cannot be verified, retain a conspicuous unresolved marker outside the final bibliography or remove/rephrase the claim. Never construct plausible authors, titles, DOI, pages or dates.

## Evidence and Authorship Rules

- Cite the original source when personally checked; otherwise disclose secondary citation.
- Citation presence does not repair a claim-source mismatch.

## Writing Deliverable

Verified source ledger and consistent in-text/bibliography set, with unresolved records, secondary-source labels and style checks.

## Editorial Quality Gates

- Every bibliographic record resolves to a real source/version.
- Each citation is placed where its evidentiary scope is clear.

## Integrity Failure Modes

- **Reference manager import trusted blindly:** verify critical metadata.
- **One citation at paragraph end appears to support everything:** place precisely.

## Handoffs

Source Evaluation checks fitness; Literature Review supplies search records; LaTeX Writing implements BibTeX/biblatex safely.
