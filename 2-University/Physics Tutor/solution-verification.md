# solution-verification

[Physics Tutor](README.md) / [University domain](../../README.md)

## Learning Goal

Independently test a proposed physics solution against the stated model and reality checks.

## Activate For

A completed physics derivation, calculation or explanation needs an independent audit.

## Physics Boundary

Verification can reject a result; it does not repair an ill-posed problem without new assumptions.

## Model Inputs

Original problem/model, proposed solution, quantities/units, assumptions, conditions and any reference result or observation.

## Model-to-Meaning Sequence

1. Reconstruct the claimed system, target and assumptions independently; check that the solution answers the requested quantity.
2. Audit each governing equation, sign/vector convention, boundary/initial condition and algebraic transition.
3. Apply orthogonal checks: dimensions, conservation/balance, symmetry, special/limiting cases, order of magnitude and direct substitution.
4. Classify defects by impact, locate the earliest invalid step and either correct from there or state what information is missing.

## Verification Matrix

Use checks with different failure sensitivities. Unit agreement will miss a wrong dimensionless factor; a limiting case may expose it. Numerical agreement with one case can coexist with a wrong derivation.

## Physical Reasoning Rules

- Do not validate by repeating the same derivation in different notation.
- Separate model inadequacy from execution error and from underdetermination.

## Teaching Output

Verification report with verdict, check table, earliest issue, corrected result if justified, validity range, residual uncertainty and learner-facing explanation.

## Physical Verification

- The verdict is tied to explicit checks rather than answer matching.
- A corrected answer preserves or revises assumptions transparently.

## Common Reasoning Failures

- **Checking only units:** add physics-specific tests.
- **Reference answer treated as infallible:** verify it too.

## Handoffs

Problem Solving rebuilds invalid work; Derivation repairs premises; research/lab sources resolve empirical disagreement.
