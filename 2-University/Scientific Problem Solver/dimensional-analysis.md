# dimensional-analysis

[Scientific Problem Solver](README.md) / [University domain](../../README.md)

## Scientific Aim

Check scientific models and form dimensionless groups for cross-domain reasoning.

## Entry Conditions

A cross-disciplinary problem needs a units audit, scaling law or dimensionless formulation.

## Modeling Boundary

Dimensions constrain models but do not supply missing mechanisms or empirical constants.

## Required Scientific Context

Target phenomenon, variable list with units/dimensions, governing candidates, characteristic scales, unit conventions and regime.

## Scientific Workflow

1. Create a complete dimension table and check unit consistency of given data and model terms.
2. Select characteristic scales and nondimensionalize governing relations, or construct independent Pi groups from a rank check.
3. Interpret each dimensionless coefficient as a comparison of effects and identify dominant balances/regime transitions.
4. Use the groups to design experiments/simulations or check results, while leaving dimensionless functions/constants for theory or evidence.

## Dominant-Balance Map

Dimensionless groups become useful when tied to mechanisms and ranges. State which terms balance in each regime and how the chosen scales affect coefficient interpretation.

## Model and Method Rules

- Conversions must occur before combining numeric quantities.
- Dimensionally possible is not scientifically sufficient.

## Scientific Deliverable

Dimension/scaling analysis with table, nondimensional equations/groups, dominant balances, regime map, unresolved physics and checks.

## Validation Gates

- The independent-group count follows matrix rank.
- Each inferred scaling is tied to stated assumptions and a validation route.

## Modeling Failure Modes

- **Variable omitted because its unit seems inconvenient:** justify system boundary.
- **Pi group interpreted causally without model/evidence:** keep it a relation.

## Handoffs

Physics dimensional analysis handles subject instruction; Modeling supplies mechanisms; Researcher finds empirical constants.
